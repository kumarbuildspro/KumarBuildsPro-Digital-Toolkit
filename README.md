🚀 KumarBuildsPro | Digital Toolkit

A Powerful All-in-One Digital Toolkit for Everyday Productivity.

KumarBuildsPro Digital Toolkit is a modern, responsive, and user-friendly web application that brings 24+ useful tools together in one place. Built using HTML, CSS, and JavaScript, it helps users perform everyday tasks quickly and easily.

✨ Features

- 📝 Text Tools – Word Counter, Case Converter, Text Reverser and more.
- 🖼️ Image Tools – Image Compressor, Resizer, Converter and Cropper.
- 🧮 Calculators – Age, Percentage, Grade and Unit Calculator.
- 💻 Developer Tools – JSON Formatter, HTML Formatter, CSS Minifier and Base64 Converter.
- 🔐 Generators – Password Generator, QR Code Generator, UUID Generator and Lorem Ipsum.
- 📅 Productivity Tools – To-Do List, Notes Manager, Pomodoro Timer and Daily Planner.

🌟 Special Features

- 🎨 Modern Dark & Light Mode.
- 🔍 Instant Tool Search.
- ⭐ Favorites and Recently Used Tools.
- 💾 LocalStorage Data Saving.
- 🔄 Data Backup & Restore.
- ⏱️ Pomodoro Timer with Refresh Persistence.
- 📱 Fully Responsive Design.
- ⚡ Fast and Easy-to-Use Interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- HTML5 Canvas API

🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Start using your favorite tools!

💾 Data Storage

The application uses browser LocalStorage to save supported user data, including favorites, history, notes, tasks, planner entries, theme preferences, and Pomodoro timer state.

Use the Backup & Restore feature to export and recover your saved data.

Note: QR Code generation requires an internet connection. Saved browser data is device/browser-specific.

🎯 Project Goal

The goal of KumarBuildsPro Digital Toolkit is to create a simple, powerful, and accessible platform where useful digital tools are available in one convenient place.
